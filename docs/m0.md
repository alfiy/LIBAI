# Libai M0

## Goal

Boot Libai on x86_64 using UEFI and QEMU.

## Architecture

UEFI
  |
  v
Libai EFI Loader
  |
  v
Libai Kernel
  |
  v
Serial / Console

## M0 Features

- x86_64
- UEFI boot
- Kernel entry
- BootInfo
- Serial output
- QEMU execution
- GDB debugging

## Not included

- Virtual memory
- Process
- Scheduler
- Filesystem
- Network
- GPU
- NPU
- AI runtime

## Success Criteria

QEMU successfully boots Libai and outputs:

Libai Kernel
Libai is the best AI kernel
